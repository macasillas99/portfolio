# Maxine Casillas Portfolio

An Angular portfolio based on the supplied retro space-interface plan: Home, Résumé, About, Projects, and a lost-signal page. Features include a starfield background, profile panels, progress indicators, technology filters, expandable project notes, source links, and a downloadable résumé.

See DEPLOYMENT.md for local setup, GitHub Pages deployment, verification, and recovery steps.

```text
npm ci
npm test -- --watch=false
npm start
npm run build:pages
```
